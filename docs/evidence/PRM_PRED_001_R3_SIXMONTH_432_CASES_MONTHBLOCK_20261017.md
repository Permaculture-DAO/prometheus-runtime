# PRM-PRED-001 — NOAA six-month, three-horizon external forecast replay (432 cases)

**Date:** 2026-10-17. **Evidence state:** candidate / noncanonical / shadow / **R3 SCIENTIFIC HOLD**.

## Scope and crucial limitation

These are **NOAA GFS** weather forecasts, **not** predictions generated by PROMETHEUS. PRM-PRED performs reproducible offline evidence checks and comparator-sensitivity diagnostics, NOT forecast creation, forecast certification, atmospheric 129-day prediction, an insurer's underwriting, or financial/land capital admission.

Three GHCNh stations: Miami `USW00012839`, Atlanta `USW00013874`, Jacksonville `USW00013889`. Six sample months **February, May, July, August, September, October 2026**. Eight forecast issue dates (days 3–10) per month, 00 UTC cycle. Three GFS lead horizons: +24h, +48h, +72h. **432 unique model forecast–station–verification events**, 144 per horizon. The identical 432 events were scored against **two baselines**, not counted twice as independent forecasts.

## Source and method

- Operational archived NOAA GFS GRIB2, 0.25 degree grid, temperature at 2 m, nearest GFS gridpoint.
- NOAA GHCNh external station temperature at verification instant matched within +/-60 minutes, **not** independently adjusted for point-grid representativeness.
- Benchmark A: latest eligible timestamped station temperature **20–180 minutes before** issue time; real-time publication latency still unverified.
- Benchmark B: NOAA `HLY-TEMP-NORMAL` from official 1991–2020 hourly climate normal for the station. NOAA uses degrees Fahrenheit and **local standard time**, here UTC−05:00, converted to Celsius and aligned to the forecast validity time; **never** incorrectly use DST to align the normal.
- Observation `temperature_Quality_Code` depends on `temperature_Source_Code`. NOAA GHCNh documentation defines **`1` as GOOD for source `223`**. An initial filter that rejected all nonempty QC fields incorrectly excluded **all 72 February cases**. The filter was corrected to admit legacy QC=1 only for explicitly documented source classes `220/221/222/223/347/348`, along with pre-existing empty quality fields for this candidate experiment. Previous 360-case trace retained as **superseded/invalid for inference**.
- All NOAA GFS archived field ranges, original station CSV/PSV partial downloads, adjacent extension ranges, normals, request/response JSON and SHA256 field hashes retained in local experimental custody. The **source authenticity, commercial use rights, availability lag, forecast version and NOAA QA interpretation still need independent reviewer acceptance**.
- Frozen replay as-of 2026-10-17T12:00Z, model training cutoff caller-declared only, independent holdout still unverified.
- Source documentation for source-specific GHCNh QC: https://www.ncei.noaa.gov/oa/global-historical-climatology-network/hourly/doc/ghcnh_DOCUMENTATION.pdf

## Reproducible temporal-dependence sensitivity

`predictability_month_blocks.py` implements deterministic, replay-seeded whole-calendar-month-block resampling that **keeps all sites and day-to-day observations of a sampled month together** to avoid the naive assumption that adjacent weather records or nearby stations are independent.

With **six temporal blocks from only one year**, the output correctly states `INSUFFICIENT_INDEPENDENT_TEMPORAL_BLOCKS`. These 2.5–97.5% exploratory resampling quantiles are **NOT frequentist confidence intervals, statistical-significance claims or an accepted forecast horizon**:

| Lead | Persistence gain resampling range °C | Climate-normal gain resampling range °C |
|---|---|---|
| +24 h | [0.651072, 1.872446] | [0.642660, 1.613312] |
| +48 h | [0.361458, 2.022498] | [0.095164, 1.272681] |
| +72 h | [0.808729, 1.783739] | [0.163659, 1.216391] |

Month blocks chosen with replacement, explicit deterministic seed from SHA256 of the frozen cases, 2048 draws per lead. Evidence authentication, legal rights, human authority and capital gates are unchanged.
